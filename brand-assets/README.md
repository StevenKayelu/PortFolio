# DevGen Ventures logo

**The mark:** a copper umbrella over three diamonds, standing for DevGen Ventures bringing its brands together. The centre diamond is the copper-diamond symbol the brand already used. It has no words, so it stays readable at favicon size (16 px).

## Files

| File | Use it for |
|---|---|
| `png/devgen-ventures-logo-horizontal-on-light.png` | Letterheads, documents, light websites (transparent background) |
| `png/devgen-ventures-logo-horizontal-on-dark.png` | Dark backgrounds, presentations (transparent background) |
| `png/devgen-ventures-logo-stacked-on-light.png` / `-on-dark.png` | Square spaces: posters, cards, signage |
| `svg/devgen-ventures-mark-on-light.svg` and `png/…-mark-on-light-*.png` | The mark alone on light backgrounds |
| `svg/devgen-ventures-mark-on-dark.svg` and `png/…-mark-on-dark-*.png` | The mark alone on dark backgrounds |
| `svg/devgen-ventures-mark-app-icon.svg` and `png/…-app-icon-*.png` | Profile pictures (WhatsApp, Facebook, LinkedIn) and app icons: navy tile, rounded corners |
| `svg/devgen-ventures-mark-square-tile.svg` and `png/…-square-tile-*.png` | The same with square corners, for places that round them for you (phones, some social sites) |
| `png/devgen-ventures-social-share-1200x630.png` | Link previews and social media covers |
| `favicon/` | The favicon set the websites use |

The SVG files scale to any size without losing quality. Use them for print and signage, and the PNGs everywhere else.

## Colours

| | Hex | |
|---|---|---|
| Deep navy | `#14243D` | Background, text on light |
| Copper gold | `#D4A648` | Canopy and side diamonds |
| Warm ivory | `#F3EFE6` | Centre diamond and text on navy |

The logo lettering is **Hanken Grotesk Bold**, in capitals with wide letter spacing (free from Google Fonts).

## Simple rules

- Leave clear space around the logo at least the width of the centre diamond.
- Don't show the mark smaller than 16 px on screen or 8 mm in print.
- Don't stretch, rotate, recolour or add effects. On photos, place it on a solid navy or white area.
- Copper text on a white background is hard to read, so use navy text on light backgrounds.

To change the logo on the websites: **Admin → Site content → Logo & favicon**.
